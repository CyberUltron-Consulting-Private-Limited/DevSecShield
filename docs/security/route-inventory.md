# Route inventory: the access policy of every route (F4 RBAC)

Generated by `backend/scripts/rbac_route_inventory.py` (its docstring has the command) on `feat/f4-rbac`.

"Checks before F4" is a static scan of each handler on `dev` 3399452: `bearer_user` verifies the Bearer token;
`team_member` / `team_admin` check membership / the admin role in the path's team; `scan_owner` compares the row's
owner with the caller; `superuser`; `link_token`, `verification_code`, `refresh_token`, `cicd_key` are credentials the
handler checks itself. Before F4 nothing made a new route do any check. Now `tests/test_rbac_route_coverage.py` fails
for a route without a policy, and calls every team route as a non-member, a superuser who is not a member, a viewer, a
member, an admin and an owner.

Policy kinds: **team**: a member of `{team_id}` whose role holds the permission (roles viewer < member < admin < owner;
the matrix is `backend/utilities/rbac/permissions.py`). **authenticated**: any signed-in account. **platform_admin**:
a superuser. **public**: the reason is stated. **machine**: a non-person credential the handler checks.
**Audited**: the middleware writes a successful request to the audit log; refused team writes are written too.
