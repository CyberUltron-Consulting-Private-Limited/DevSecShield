- Root cause of most AIBOM dashboard bugs is ONE defect: the pipeline isn't model-aware. The model-reference scanner emits models the graph/compliance/license/scorer/model-card layers don't read. Fixing A2 (canonical model node) + A3 (graph edges) clears "no model component", the 53 false-unlicensed (A4), and the broken supply-chain graph together. Sequence these early.

- Compliance N/A is partly a bug (models not graph-wired) and partly correct (Chroma is not a clinical device; GMLP is out-of-scope, not fail). A9 introduces the tri-state.
- The PRODUCT ships NO runtime LLM (MVP): enrichment is deterministic (known-model KB + regex/AST), behind a provider interface so an LLM (Anthropic API or Bedrock) can be added later only if a customer requires it. Claude Code's OAuth login (the agent) is separate. Product ships no OSS BOM tool; oracles (Trusera/Cisco/CBOMkit) are bench/ only.
- CBOM = CycloneDX 1.6 crypto-asset (ECMA-424): 4 categories (algorithm/certificate/protocol/related-crypto-material) + nistQuantumSecurityLevel. Weak algos to flag: MD5, SHA-1, DES, 3DES, RC4, RSA<2048, ECB. PQC targets: ML-KEM/ML-DSA/SLH-DSA (FIPS 203/204/205); NIST deprecates RSA/ECC after 2030, disallows 2035.
